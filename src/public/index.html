    What our agents never do the full text is ETHICS.md in the repo
      You can take back control at any moment

      The button on the phone — “This is genuine — stop” — ends the engagement immediately, mid-turn, with no confirmation step. It sends one neutral line so the thread does not stop dead, marks the session a false positive (which is terminal — no later message re-escalates it), and offers to add the caller to the trusted list so they are never baited again.

      False positives

      Baiting a real caller is the worst thing this system could do, so a hand-off needs a hard signal and not just a high score; SUSPICIOUS warns and never baits; a legit label caps the state; and a trusted contact is never engaged whatever the score. The rate is measured and printed by the test suite, which fails if one legitimate message out of twenty reaches the decoy.

      Data retention

      Sessions are deleted 30 days after they were last seen, by a sweep that runs at boot and every six hours. The window is configurable with SESSION_RETENTION_DAYS; setting it to 0 keeps sessions indefinitely and logs a warning on every boot. A report never contains the protected user's real name, number or address.

      Nothing is filed automatically

      No report is submitted to 1930, cybercrime.gov.in or anywhere else. There is no outbound path in the codebase. A report stays a draft until a family member has read it, and filing it is their decision.
