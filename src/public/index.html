Chakravyuh

A three-agent defensive system for scam calls and chats.

Status

The API is running. The operator console is built in a later phase; for now the endpoints below are the interface.

Endpoints

  • GET /health — no key required
  • POST /api/message — one inbound message
  • GET /api/sessions — recent sessions
  • GET /api/sessions/:sessionId — one session in full

Every route except /health requires an x-api-key header.

The decoy only ever replies after the Guardian has confirmed a scam. On a legitimate caller the response carries the assessment and reply: null.
